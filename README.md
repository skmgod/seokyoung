# 크라우드 주택관리 프로그램

빌라·다가구·원룸 관리비 부과와 수납을 관리하는 웹 프로그램입니다.
기존 PowerBuilder 프로그램(panme041)의 업무 흐름을 기준으로 새로 만들었습니다.

## 실행

`실행.bat`을 더블클릭하면 필요한 부품을 설치하고 브라우저가 열립니다.
처음 접속하면 관리자 계정을 만드는 화면이 나옵니다.

같은 사무실의 다른 PC에서는 실행 창에 표시된 `http://(IP):5000` 주소로 접속합니다.
(Windows 방화벽에서 5000번 포트 허용이 필요할 수 있습니다.)

기본 설정에서는 자료가 `instance/housing.db` 파일 하나에 모두 저장됩니다. **이 파일을 주기적으로 백업하세요.**

## Supabase(클라우드 DB)에 저장하기

1. `.env.example`을 복사해 `.env`로 이름을 바꿉니다.
2. Supabase 대시보드 → 프로젝트 → 상단 **Connect** → **Session pooler** 연결 문자열을 `DATABASE_URL=` 뒤에 붙여넣고,
   `[YOUR-PASSWORD]`를 데이터베이스 비밀번호로 바꿉니다.
3. `실행.bat`으로 다시 실행하면 표가 자동으로 만들어지고, 왼쪽 아래에 `저장소: Supabase`가 표시됩니다.

- 표는 `public` 스키마에 만들어지며, Supabase API(anon 키)로는 읽거나 쓸 수 없도록 RLS가 켜집니다.
- `.env`에는 비밀번호가 들어 있으므로 GitHub에 올라가지 않게 `.gitignore`에 들어 있습니다.
- SQLite로 쓰던 자료는 자동으로 옮겨지지 않습니다. 필요하면 [기존 자료 가져오기]로 다시 올리세요.

## Vercel에 배포하기

Vercel은 파일을 저장할 수 없으므로 **Supabase 연결이 필수**입니다.
Vercel 프로젝트 → Settings → Environment Variables에 다음 두 값을 넣고 Redeploy 하세요.

| 이름 | 값 |
|---|---|
| `DATABASE_URL` | Supabase → Connect → **Transaction pooler**(포트 6543) 연결 문자열 (비밀번호 포함) |
| `SECRET_KEY` | 긴 임의 문자열 (예: 비밀번호 생성기로 만든 40자 이상) |

값이 빠졌거나 DB 연결에 실패하면 사이트에 원인이 표시됩니다.

## 월 업무 순서

1. **빌라·세대 관리** – 빌라 등록, 공과금 부과 방식, 월 고정 관리비 항목, 세대(호수) 등록
2. **검침 입력** – 세대별 당월 지침과 빌라 전체 고지금액(한전·수도사업소 등) 입력
3. **관리비 계산** – 빌라를 선택해 월 관리비 부과
4. **부과 내역·고지서** – A4 한 장에 2세대씩 고지서 출력
5. **수납 입력 / 일괄 수납** – 수납액은 가장 오래된 미납부터 자동으로 차감
6. **미납 관리** – 미납 세대 조회, 독촉장 출력

## 계산 규칙

- 공과금 부과 방식: 사용량 × 단가 / 고지금액을 사용량 비율로 배분 / 세대 균등 분할
- 관리비 항목: 세대당 금액(세대별 금액 지정 가능) 또는 총액을 입주 세대수로 분할
- 공실 세대, 입주일 이전 세대, 퇴거일이 지난 세대는 부과하지 않음
- 납기후 연체료 = 당월 부과액 × 연체료율. 납부기한까지 당월분을 완납하지 않으면 적용
- 금액 단위(1/10/100원)와 버림·반올림·올림은 설정에서 선택

## 기존 자료 가져오기

기존 프로그램에서 엑셀로 저장한 세대 목록(빌라명, 호수, 성명, 연락처, 입주일, 보증금, 임대료, 월관리비, 미납액)을
**기존 자료 가져오기** 메뉴로 올리면 미리보기 후 저장됩니다. 미납액은 '이월 미납'으로 들어갑니다.

## 파일 구성

| 파일 | 내용 |
|---|---|
| `app.py` | 화면(웹 페이지) 처리 |
| `billing.py` | 관리비 계산, 연체료, 수납 배정 |
| `importer.py` | 엑셀/CSV 가져오기 |
| `db.py` | 데이터베이스 구조 |
| `templates/` | 화면 HTML |
| `serve.py` | 운영용 서버 실행 |
